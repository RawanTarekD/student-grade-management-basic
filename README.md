# Student Grade Management System

A beginner-friendly Python project for managing student records and analyzing academic performance through a simple menu-driven program.

## Overview

The Student Grade Management System allows users to manage student information, record subject grades, calculate averages, and generate basic class statistics.

This project was developed to practice Python fundamentals and problem-solving skills.

## Features

* **Add Student:** Enter student information, subjects, and grades.
* **Show Students:** Display saved student records.
* **Search Student:** Find a student by name.
* **Calculate Average:** Calculate students' average grades.
* **Grade Classification:** Assign performance levels based on average scores.
* **Class Statistics:** Display the total number of students, highest and lowest averages, class average, and student counts by grade category.
* **Input Validation:** Validate age, number of subjects, and grade values.

## Grading System

| Average Score   | Classification |
| --------------- | -------------- |
| 85–100          | Excellent      |
| 75–less than 85 | Very Good      |
| 60–less than 75 | Good           |
| 50–less than 60 | Passed         |
| Below 50        | Failed         |

## Technologies Used

## How to Run

1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python "Student Grade Management System.py"
```

5. Follow the menu instructions to use the program.
